# Code Forge Assets Directory

## Logo File

Please place your official **Code Forge** logo image here as `logo.png`.

### Requirements:
- **Filename:** `logo.png`
- **Format:** PNG (with transparency preferred)
- **Recommended sizes:**
  - Width: 200-300px for optimal display
  - Height: Proportional to width
  - Maximum file size: 100KB for fast loading

### How the logo is used:
The logo appears in these locations:
1. **Main Navigation** - Header bar (42px height)
2. **Auth Pages** - Login/Signup screens (56px height)
3. **Footer** - Site footer (40px height)
4. **All pages maintain consistent logo sizing**

### Important Notes:
- Do NOT modify, recolor, or apply effects to the original logo
- The image should be on a transparent background
- Ensure sufficient contrast on both dark and light themes
- Test that the logo looks sharp at all sizes
